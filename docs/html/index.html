RailInsight¶

Cette application Streamlit étudie les gares d'arrivée TGV où les retards pourraient créer une demande supplémentaire de taxis et de VTC. L'Indice de Consommation Potentielle (ICP) est une simulation sous hypothèses, pas une mesure de courses réservées ou de rentabilité réelle.
