Nettoyage¶

Nettoyage et contrôle qualité des données de régularité des trains TGV.

Par étape : - importation de variables et classes provenant de classDF (voir commentaires plus bas); - définition de la fonction triDF() qui sera reprise dans core.py

La fonction triDF() applique les opérations suivantes :

  • vérifier la présence des colonnes obligatoires ;

  • conserver uniquement le service National et exclure les années 2020 et 2021 ;

  • harmoniser les effectifs cumulés de retard pour respecter N15 >= N30 >= N60 ;

  • retirer les lignes aberrantes selon la durée du trajet, les effectifs et les avances excessives ;

  • marquer les autres incohérences et les doublons avec eligible, puis exporter les colonnes utiles dans le CSV nettoyé.

Une somme des parts des causes différente de 1 n'est pas un critère de suppression dans triDF(). Lors du calcul de l'ICP, ICPCalculator.calculer_ligne() traite les parts manquantes comme nulles et re-normalise les parts disponibles. Si leur somme est nulle, le poids de cause est neutre, à 1. Ce traitement ne modifie pas les parts exportées dans le CSV.

my_package.triDF.triDF(file_path=Path('data/regularite-mensuelle-tgv-aqst.csv'), output_path=Path('data/regularite_tgv_clean.csv'))¶

Nettoyer, renommer et contrôler les observations avant leur export CSV.

Paramètres:

  • file_path (Path)

  • output_path (Path)

triDF() renvoie cinq éléments : le DataFrame brut, le DataFrame nettoyé, les colonnes retirées, les indices de toutes les lignes retirées, et les indices des observations National des années exclues. Les retraits totaux comprennent les services autres que National, les années exclues et les anomalies, sans double comptage. La dernière liste est incluse dans les retraits totaux : ne pas additionner leurs longueurs.

Interface¶

src/app.py définit les sept onglets Streamlit. Les calculs d'ICP et de régression sont délégués à core et my_package. Importer ces modules ne lance pas de nettoyage ; core.load_data() le déclenche explicitement.
